# 🧮 Calculatrice Qt

Projet de calculatrice graphique développé en **C++ avec Qt**.

L'objectif de ce projet était de découvrir la création d'une application graphique avec Qt, puis d'ajouter progressivement la logique permettant de réaliser des opérations mathématiques.

## 📈 Évolution du projet

### 🟢 Première version — Création de l'interface

La première étape du projet consistait à créer l'interface graphique de la calculatrice avec **Qt Designer**.

L'interface comprend :

- les chiffres de 0 à 9
- addition `+`
- soustraction `-`
- multiplication `*`
- division `/`
- bouton `=`
- bouton `C`
- zone d'affichage

À ce stade, l'objectif était principalement de découvrir Qt Widgets et la conception d'interfaces graphiques.

### 🔵 Version 1 — Ajout des fonctionnalités

La deuxième étape consistait à rendre la calculatrice fonctionnelle.

Les boutons permettent alors de construire une expression directement dans l'afficheur.

Le bouton `=` permet d'évaluer l'expression saisie et d'afficher le résultat.

Fonctionnalités :

- saisie des chiffres
- addition
- soustraction
- multiplication
- division
- calcul du résultat
- gestion de l'affichage

### 🟣 Version 2 — Nouvelle version

Une nouvelle version du projet a ensuite été commencée afin de retravailler la structure de l'application et de poursuivre son évolution.
